<h1 align="left">✅ React To-Do List App</h1>

###

<p align="left">A clean and responsive To-Do List application built with React.js and Tailwind CSS, featuring task filtering, editing, sorting, and a dark mode toggle.</p>

###

<h2 align="left">🚀 Features</h2>

###

<p align="left">✍️ Add, edit, and delete tasks<br><br>✅ Filter tasks by All, Completed, or Active<br><br>🌙 Dark Mode toggle<br><br>📱 Fully responsive UI using Tailwind CSS<br><br>💾 Local storage support to keep tasks saved</p>

###

<h2 align="left">🛠️ Built With</h2>

###

<p align="left">React.js (Functional Components & Hooks)<br><br>Tailwind CSS<br><br>JavaScript (ES6+)<br><br>LocalStorage API</p>

###

<h2 align="left">📌 Future Improvements</h2>

###

<p align="left">Drag & drop task reordering<br><br>Task deadlines and reminders<br><br>Authentication to save user tasks in a backend (Firebase)</p>
